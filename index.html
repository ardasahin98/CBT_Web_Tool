    Estimate cyclic behavior type from a CDSS test

    CBT ranges from 0 (clay-like) to 1 (sand-like). It is estimated from test metrics computed for every loading cycle.

    1. Download the CSV template and fill in one file per test.
    2. Upload one or more files (or load an example).
    3. Review the metrics and CBT at the last cycle, or pick any other cycle.
